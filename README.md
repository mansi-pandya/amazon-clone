# 🛒 Amazon Clone

A responsive **Amazon Clone website** built using **HTML and CSS**.  
This project recreates the basic layout and visual design of Amazon's e-commerce homepage for learning and practice purposes.

## 🚀 Features

- Amazon-inspired navigation bar
- Search bar UI
- Account and cart sections
- Product category sections
- Product cards with images and prices
- Promotional/banner sections
- Footer with multiple links
- Responsive layout for different screen sizes
- Clean and structured HTML and CSS

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **Font Awesome** – Icons

## ▶️ How to Run

1. Clone this repository:

```bash
git clone <your-github-repository-url>
```

2. Open the project folder.

3. Open `index.html` in any modern web browser.

No additional installation or dependencies are required.
